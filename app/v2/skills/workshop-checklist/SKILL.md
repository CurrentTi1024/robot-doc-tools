# Checklist

Use the requirement and preferred slide supplied by the service. Read the preferred slide first when it is available. If the requirement is only partially supported there, retain the useful evidence and inspect the remaining eligible body slides. Evidence on any eligible slide can satisfy the requirement.

A heading, a prompt from the template, or a promise to provide a detail is insufficient. Match the actual content to the requirement. Prefer editable text, tables and explicit flow connections. Inspect a crop when native objects cannot answer the question. If the target is embedded in a dense picture, locate it first, then inspect that region.

Return `present` only when all conditions are supported. Return `missing` after checking the eligible evidence and confirming the required detail is absent. Use `uncertain` when a relevant region cannot be read or the evidence conflicts. Cite only inspected object IDs.
